# 🎓 AI Teacher Hub

منصة تعليمية ذكية بالذكاء الاصطناعي — شرح، تلخيص، حل واجبات بالصور، اختبارات تفاعلية، محادثة صوتية، جدول دراسي مخصّص، نظام Streak وأوسمة ولوحة صدارة، ولوحات تحكم منفصلة للطالب والمعلم وولي الأمر والمدرسة والوزارة.

مبادرة **اتحاد طلاب مدارس محافظة القاهرة** بالشراكة مع **مؤسسة شباب القادة (YLF)** و**قادة مدارس الجمهورية (SU)**.

---

## 🧱 التقنيات المستخدمة

- **Backend:** Node.js + Express
- **Database:** SQLite (عبر `better-sqlite3`) — ملف واحد محلي، مفيش سيرفر DB منفصل مطلوب
- **Auth:** JWT + httpOnly cookies + bcrypt لتشفير الباسورد
- **AI:** OpenRouter API (نموذج `openai/gpt-4o-mini`)
- **Frontend:** HTML/CSS/JS خام (Vanilla) — من غير أي framework، ملف واحد `index.html`

## 🚀 التشغيل محليًا

### 1. المتطلبات
- Node.js نسخة 18 أو أحدث

### 2. التثبيت
```bash
npm install
```

### 3. متغيرات البيئة
اعمل نسخة من `env.example` باسم `.env` بالظبط (لازم تبدأ بنقطة، من غير أي امتداد زيادة):

```bash
cp env.example .env
```

وبعدين افتح `.env` واملأ القيم دي:

| المتغير | إجباري؟ | الوصف |
|---|---|---|
| `OPENROUTER_API_KEY` | ✅ إجباري | مفتاح API من [openrouter.ai/keys](https://openrouter.ai/keys) |
| `JWT_SECRET` | ✅ إجباري | قيمة عشوائية طويلة وسرية لتشفير جلسات الدخول. ولّدها بالأمر: `node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"` |
| `PORT` | اختياري | البورت المحلي (افتراضي 3000) |
| `NODE_ENV` | اختياري | `development` أو `production` |
| `ALLOWED_ORIGIN` | اختياري | مطلوب بس لو الفرونت إند شغّال على دومين مختلف عن الباك إند في الإنتاج |

⚠️ **مترفعش ملف `.env` على GitHub أبدًا** — ده معمول له `.gitignore` بالفعل.

> **ملاحظة:** مكتبة `better-sqlite3` بتحتاج تجميع (Compile) وقت التثبيت لأول مرة على بعض الأنظمة. ده بيشتغل تلقائي وطبيعي على Railway وأي بيئة استضافة حقيقية (عندها اتصال إنترنت كامل). لو ظهر خطأ غريب وقت أول Deploy بيتكلم عن `node-gyp` أو تجميع، جرّب تتأكد إن نسخة Node.js المستخدمة 18 فأكتر (Railway بيحددها من `engines` في `package.json` تلقائيًا).

### 4. التشغيل
```bash
npm start        # تشغيل عادي
npm run dev       # تشغيل مع إعادة تشغيل تلقائي وقت التعديل (nodemon)
```

هيفتح على `http://localhost:3000`

## ☁️ النشر (Deployment)

### ✅ Railway (الموصى به)
المشروع ده مبني على **سيرفر Node.js دائم الاتصال + قاعدة بيانات SQLite بملف محلي**، وده بالظبط اللي Railway مصمم له.

1. اعمل Push للمشروع على GitHub
2. من [railway.app](https://railway.app) اعمل **New Project → Deploy from GitHub repo**
3. من تبويب **Variables**، ضيف نفس المتغيرات اللي في الجدول فوق (`OPENROUTER_API_KEY`, `JWT_SECRET`, وممكن `NODE_ENV=production`)
4. **مهم جدًا:** من إعدادات الـ Service، فعّل **Volume** (قرص دائم) واربطه بمسار المشروع، عشان ملف `data.db` (قاعدة البيانات وكل حسابات المستخدمين) يفضل محفوظ بين كل عملية Deploy جديدة. من غير Volume، أي Deploy جديد هيمسح كل البيانات.
5. Railway هيكتشف `npm start` تلقائيًا من `package.json` ويشغّل المشروع.

### ⚠️ Vercel — غير مناسب لهذا المشروع بالشكل الحالي
Vercel مبني أساسًا لتطبيقات **Serverless** (functions بتشتغل لحظة الطلب وتقفل، مفيهاش تخزين دائم بين الطلبات). المشروع ده بيعتمد على:
- سيرفر Express **دائم التشغيل** (مش Serverless Functions)
- قاعدة بيانات **SQLite بملف على القرص** (Vercel مفيهوش تخزين ملفات دائم بين الطلبات)

لو حبيت تنشره على Vercel لازم تعمل تعديل معماري كامل: تحويل `server.js` لـ Serverless Functions منفصلة، واستبدال SQLite بقاعدة بيانات سحابية زي **Postgres** (مثلاً عبر [Neon](https://neon.tech) أو [Supabase](https://supabase.com), وكلاهم بيشتغل مجانًا مع Vercel). ده شغل إضافي مش جزء من التسليم الحالي.

**التوصية: استخدم Railway مباشرة بالكود الحالي من غير أي تعديل.**

## 📁 هيكل المشروع

```
├── index.html          # الواجهة كاملة (HTML + CSS + JS الأساسي مدمج)
├── script.js           # منطق الواجهة (Fetch، عرض البيانات، كل الميزات التفاعلية)
├── server.js           # سيرفر Express + كل الـ API endpoints
├── db.js               # إعداد قاعدة البيانات SQLite + المخطط (Schema) + الـ Migrations
├── auth.js             # دوال التسجيل/الدخول: تشفير الباسورد، JWT، الـ Middleware
├── package.json         # الاعتماديات وأوامر التشغيل
├── env.example          # قالب متغيرات البيئة (انسخه لـ .env واملأه)
├── .gitignore            # يمنع رفع .env و node_modules و data.db بالغلط
├── logo-ylf.png          # شعار مؤسسة شباب القادة (خلفية شفافة)
├── logo-su.png            # شعار قادة مدارس الجمهورية (خلفية شفافة)
└── logo-csu.png            # شعار اتحاد طلاب مدارس القاهرة (خلفية شفافة)
```

## ✨ الميزات

- 🎓 شرح / تلخيص / أسئلة اختبار — بالذكاء الاصطناعي
- 📸 حل الواجبات من صورة (تصحيح أو حل خطوة بخطوة)
- 📝 اختبار تفاعلي فعلي بأسئلة اختيار من متعدد وتصحيح فوري
- 🎙️ محادثة صوتية ثنائية اللغة (عربي/إنجليزي) بذاكرة سياق
- 📅 جدول دراسي أسبوعي مولّد بالذكاء الاصطناعي
- 🔥 نظام Streak ونقاط وأوسمة تحفيزية
- 🏆 لوحة صدارة (عامة/على مستوى المدرسة)
- 🔐 تسجيل دخول حقيقي بـ 6 أنواع حسابات (طالب، معلم، ولي أمر، مسؤول مدرسة، وزارة، شركة دروس)
- 🎛️ 5 لوحات تحكم منفصلة: الطالب، المدرسة، المعلم، ولي الأمر، الوزارة
- ♿ نظام سهولة وصول شامل: تباين عالٍ، تكبير الخط، تقليل الحركة، قراءة صوتية بالعربي، تدرج رمادي، مؤشر كبير، مسطرة قراءة، ووضع مسح بمفتاح واحد لذوي الإعاقة الحركية الشديدة
